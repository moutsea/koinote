## Conversation continuity (2026-11-17)

`conversation-continuity.patch` separates intent interpretation from the application execution contract, while keeping that contract in execution, independent operation review and final-response review. It also adds a shared discourse rule: previous assistant messages may establish what a later user instruction refers to without supplying authorization themselves. Completed steps must not freeze the next actionable goal. Assistant descriptions of what they did not change are not user prohibitions; unrelated product features are not competing interpretations merely because a word matches. Regressions cover both initial interpretation and clarification review, preserving native history, execution instructions and independent review restrictions.

This does not bypass review, accept denied operations, relax provenance validation or change permissions. Genuine unresolved choices still require clarification. Apply on top of the currently active source archive after checking whether the change is present, preserving the earlier constraint-scope fix and every subsequent release. The active source was read-only verified as `23ecf95f-9a1c-4e50-85e6-c5e87540d207` during diagnosis; re-query before any future release.

The Koinote fixture `TestAgentCoverConversationContext` exports the host envelope for the supplied conversation fragment through `KOINOTE_TEST_CONTRACT_DIR`. `scripts/fixtures/koi-cover-context.eval.ts` is a separately opted-in, billable semantic replay against the configured application channel. It supports the old envelope, a continuity-only envelope, the complete local configuration, and a genuinely ambiguous control. Article data, prior inferred state and tool receipts are synthetic; this does not substitute for the original production trace or a production acceptance test. Verification results and limitations are recorded in `docs/KOI_AI_COVER_APPLICATION.zh.md`.

The no-cover-capability counterfactual still produced unnecessary clarification even with the core changes. Do not describe the patch as a complete solution to general context understanding. The supported cover workflow and genuine-ambiguity control passed real-model replay; prompt-only or capability-free replay did not consistently pass.
