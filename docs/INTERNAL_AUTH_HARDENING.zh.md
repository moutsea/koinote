# 内部鉴权与源站保护修复（2026-11-20）

本轮已实施生产封堵、凭据轮换和首轮敏感信息核查。腾讯云微信中继机由用户保持停机；
本记录不代表已定位或修复该机器的入侵入口。

## 根因与实际改动

1. Caddy 的普通 JSON 日志会保存自定义内部鉴权头。生产旧访问日志确实含有效内部令牌；
   标准 Cookie/Authorization 的默认脱敏不覆盖该自定义头。
   访问日志和运行错误日志现均删除全部请求/响应头及 URL 查询参数，单独保留排障需要的 IP、
   UA、路径、状态。旧日志已保全并移至 root 专有隔离目录，新日志显式使用 `0600`。
2. 源站原允许公网直连，却把调用者提供的 `CF-Connecting-IP` 转发给按 IP 限流的后端。
   现新增独立 `BACKEND_ORIGIN_TOKEN`：受保护接口须经过本项目 Worker；仅 `/health` 保持公开。
   Worker 覆盖调用者伪造的源站头，API、图片鉴权/记账、分享预览和 SEO 回源均携带该独立凭据。
   图片及分享回源也禁止自动跟随跳转，避免将服务凭据带往其他地址。
3. 已轮换 `BACKEND_INTERNAL_TOKEN`，同步 Worker、后端、备份任务和 GitHub Actions Secrets。
   源站凭据与内部 API 凭据使用不同随机值；模板不含真实值，部署检查长度及二者不同。
   日后部署会先校验新 Caddy 配置，再重新创建其文件挂载和环境，避免 rsync 替换文件后仍运行旧配置。
4. 用户不认识的来源已加入 Worker 的 `SECURITY_BLOCKED_IPS` 入口规则。
   已提升现有账户会话版本，并撤销未标记撤销的桌面访问/刷新令牌，阻断可能保留的旧登录态。
   用户需要重新登录。没有更改用户密码、文章或支付权益；未对未证实泄露的其他服务密钥做破坏性轮换。

受影响的完整链路为：客户端 → Worker → Caddy → Go 会话鉴权/限流；
Go → Worker 的内部对象、图片回收、邮件及备份接口继续使用轮换后的内部 API 令牌。
源站凭据只随请求发往自有后端，不附加到外部图片抓取请求。

- 使用真实 Caddy 镜像在无外部网络的隔离容器中制造实际 502，确认访问日志及运行错误日志

- 生产实测：直连受保护源站及伪造源站凭据均为 403；经 Worker 的未登录会话检查为 401；
  主站健康、公开页面及 Koi AI 就绪检查正常。
- 生产实测：旧内部令牌访问内部对象存储和备份状态均为 401；新令牌分别为 204、200。

  没有修改真实用户文章，没有调用付费模型或发验证邮件。
- 旧会话版本的实际生产请求被拒绝。真实 Koinote 用户口令登录未作为已通过的验收项：
  一次误用本地 Agent 管理台凭据的检查返回 401，已排除；未修改管理员密码，服务日志未匹配该口令。

## 敏感信息核查与边界

检查了 634 个 Git 提交、5,859 个 blob、12 次近期 Actions 日志和约 3 万条保留访问日志。
已知当前生产凭据比对确认的落日志内容是已作废的内部令牌；未匹配到数据库密码、模型 API Key
或微信中继 SSH 私钥。旧日志另有一条 Google OAuth 回调临时代码，已作为潜在敏感信息封存。
新日志及当前容器日志未匹配新内部令牌、源站凭据或已知其他生产密钥。
这些结论只覆盖已取得的记录和已知凭据，不能当作“从未外泄”的证明。

已核对可疑来源的注册、登录、接入令牌、付费状态和敏感接口请求：观察到两个当天注册的免费普通账户，
两次文档列表响应与空列表一致，当前没有文档；未发现管理员权限、近期模型渠道修改、
新建 MCP 令牌或 MCP 令牌明文揭示成功记录。尚未完整归属每条登录成功记录，
也没有证据确认其读取了其他用户的文档。现有合法 MCP 集成没有被无差别撤销。

Cloudflare 数据中观察到可疑备份下载被 401 拒绝；204 的对应源站请求是 OPTIONS，不能当作数据下载。
自适应分析可能抽样，Worker 内部存储访问也不会全部进入源站访问日志，因此不能由此排除所有历史访问。
本轮没有读取普通用户文章内容；原始证据及含个人信息的数据库元数据仅存于本机/服务器受限目录，未入库。

## 后续部署约束

生产后端 `.env`、Worker Secrets 和 GitHub Actions Secrets 必须保持一致，源站凭据不得复用内部令牌。
本地开发使用独立凭据。生产 Caddy 缺少源站凭据时应明确失败，不能降级为公开源站。

不要直接回退到带有旧凭据的 Worker 版本或恢复旧 `.env`。如需回退功能代码，须在当前凭据上重新发布，
保留日志脱敏与源站保护。不得将已封存的原始日志复制进公开问题、CI 输出或仓库。
登录事件目前没有完整的账户/IP 历史审计，改进审计属于后续工作，不作为本次已实现功能。
