# Koinote 产品路线图

这份路线图记录近期最值得投入的产品与工程方向。它不是发布日期承诺；优先级会根据用户反馈、安全风险和维护成本调整。

## P0：近期重点

- [x] 账号安全：密码找回、修改密码、主动失效其他设备会话。
- [x] 移动端编辑器：用文档抽屉替代桌面文件树，保持正文可用空间。
- [ ] 自动备份与恢复：提供可验证、可下载、可恢复的站点级备份流程。
- [x] 数据可携带性：支持 `.md`、文件夹和 ZIP 的批量导入，以及全部文档、目录与图片的一次性导出。
- [ ] 账号注销：提供自助删除账号及全部关联数据的入口。
- [ ] 终生会员边界：明确长期存储、未来 AI 权益与异常成本的产品规则。

## P1：核心体验

- [x] 全局搜索：按标题与正文检索，支持快捷键唤起、结果高亮和快捷跳转。
- [x] 批量导入导出：支持 Markdown 文件、文件夹或 ZIP 连同引用图片双向迁移。
- [ ] MCP 活动日志：让用户查看 Agent 的读取、写入、冲突与撤销记录。
- [ ] 文档级权限：为 MCP 令牌限定可访问的文档或文件夹。
- [x] 分享增长能力：动态网页标题、OpenGraph 卡片、阅读次数和“复制到我的 Koinote”。
- [x] 产品漏斗：在不收集正文、标题、搜索词和文件名的前提下观察首次行为与留存。

## P2：后续探索

- [ ] 受控原生 AI：由用户明确触发，并让模型调用、费用和数据边界可见。
- [ ] 发布工作流：管理多平台发布状态、更新时间与导出记录。
- [ ] 离线与 PWA：改善弱网编辑、草稿同步和安装体验。
- [ ] 版本差异：提供可读的逐行或块级 Diff，而不只是完整版本恢复。

## 原则

- 文档内容默认私有，权限校验始终落在后端。
- Agent 写入必须保留并发保护与可恢复边界。
- 新能力优先使用开放格式和标准协议，避免锁定用户数据。
- 安全、备份和数据迁移优先于装饰性功能。
